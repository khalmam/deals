How it works

  1. 1. NegotiateThe agent proposes prices. The rules engine sets the window, and the model can only pick inside it.
  2. 2. HoldA PayPal order with intent AUTHORIZE holds the money for up to 29 days. It is a hold, not escrow.
  3. 3. DeliverCapture happens only after confirmed delivery. If terms change, the agent voids the hold.
  4. 4. Pay outApproved sub-contractors are paid, and PayPal webhooks confirm each payout.

Built on PayPal

  • Orders with intent AUTHORIZE for the payment hold. The agreed terms’ hash is stored in the hold’s custom_id.
  • Payments for capture, void and refund.
  • Payouts to the approved sub-contractors.
  • Webhooks, signature-verified and applied once per event.
